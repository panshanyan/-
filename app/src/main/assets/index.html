開啟任何一份 Betaflight 黑盒子 log

支援 .bbl、.bfl、.txt、.zip，以及 Blackbox Explorer 匯出的 .csv。可以一次選多份，選兩份就能 A/B 比較調參前後。

首頁會用白話告訴你飛機哪裡有問題、該怎麼改；其他分頁是 PIDtoolbox 風格的工具：油門×頻率熱圖、步階響應、PID 誤差、濾波延遲、飛行統計。

飛行曲線 （顯示 A）

左右拖曳圖表移動時間；紅色底是偵測到的非操作震盪。

油門 × 頻率

熱圖橫軸是頻率、縱軸是油門，越亮代表該油門下那個頻率的晃動越大。和「搖桿指令」比較：指令沒有、陀螺卻有的能量，就是雜訊、propwash 或震盪。

步階響應

用反卷積從搖桿指令和陀螺算出：打一個瞬間的桿量，飛機實際怎麼跟上。理想是快速到 1.0、小過衝（約 0–10%）、不回彈。過衝大 → D 不足或 P 太高；太慢 → 提高 P 或 feedforward。

PID 誤差 vs 油門

只看搖桿低於100°/s

PID 誤差＝搖桿指令 − 實際角速度。排除大動作翻滾後，誤差越小代表越穩、越跟手；用來客觀比較兩次調參。
